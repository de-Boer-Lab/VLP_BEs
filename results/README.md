# results/

Pipeline outputs. Everything under `results/` is generated by the Snakefiles in
[`../workflow/`](../workflow/README.md) — nothing here should be hand-edited.

Running the full pipeline (`Snakefile_Fastqc` → `Snakefile_demux` →
`Snakefile_crispresso`) from a fresh `data/` input produces:

| Path | Produced by | Contents |
|---|---|---|
| `qc/` | `Snakefile_Fastqc` | FastQC (`raw/`, `merged/`) + `multiqc_report.html` |
| `merged/` | `Snakefile_Fastqc` | Per-sample PEAR-merged FASTQs |
| `replicates/` | `Snakefile_demux` | Per-sample, per-replicate demultiplexed FASTQs + read-count summaries |
| `crispresso/` | `Snakefile_crispresso` | Raw `CRISPRessoPooled` output per sample × replicate, plus `summary/editing_summary.tsv` |
| `crispresso_aggregated/` | `Snakefile_crispresso` | `CRISPRessoAggregate` output per base editor × replicate |

## `crispresso_tables/` (tracked in git)

This subfolder is the one exception: it's a **curated, hand-picked copy** of the
modification/substitution/summary tables from `crispresso/`, checked into the repo so
figures can be regenerated with [`crispresso_analysis.R`](../workflow/scripts/README.md)
without re-running the full sequencing pipeline. See
[`crispresso_tables/README.md`](crispresso_tables/README.md) for its contents and file
naming.

All other subfolders above (`qc/`, `merged/`, `replicates/`, `crispresso/`,
`crispresso_aggregated/`) are regenerated by Snakemake and are not tracked in git (see
the repo-root `.gitignore`).
